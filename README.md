# Student Grade Calculator

A beginner-friendly Python project that calculates:
- subject-wise weighted points
- SGPA
- simple grade summary

This is a good starter project for a Computer Science student GitHub profile.

## Features
- Takes subjects, credits, and grade points
- Calculates total credits
- Calculates SGPA
- Prints a clean result table
- Includes sample input data

## Project Structure
- `grade_calculator.py` → main Python program
- `sample_scores.json` → sample subject data
- `requirements.txt` → project dependencies
- `.gitignore` → ignore Python cache files

## How to Run
1. Install Python 3
2. Open terminal in the project folder
3. Run:

```bash
python grade_calculator.py
```

## Example Use Case
You can edit `sample_scores.json` and replace the values with your own subjects and grades.
